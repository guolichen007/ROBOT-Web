# 工业中控与巡检升级说明

## 1. 首页设计

实时监控页采用单屏高性能 HMI：低饱和石墨灰承载正常状态，蓝色表示当前选择/运行，琥珀表示警告，红色只用于火情、严重故障和软件急停。首页 60% 为二维停车场地图，40% 为车顶实时视频、传感器与活动报警；主要控制始终位于底部，无需滚动。

地图按实际停车场拓扑显示 54 个车位、道路方向、规划/已执行轨迹、机器人航向、火情车位和右侧检测扇区。检测几何使用传感器相对 `base_link` 的 `x/y/yaw` 安装外参，并以检测扇区与车位 polygon 相交作为覆盖判定，不只检查车位中心。

## 2. 操作语义

- 开始巡检：创建使用已发布地图快照的巡检任务。
- 停止巡检：并行发出 `cancel_task` 与高优先级 `stop_motion`；任务取消、停止 ACK 与连续 5 帧新鲜低速遥测全部满足后，才显示“车辆已停止”。
- 返回等待区：使用独立返回命令，不与灭火任务静默冲突。
- 软件紧急停止：单击立即发送，不弹出延迟响应的确认窗；它不等于物理急停，ACK 前只显示“等待确认”。
- 手动控制：收纳在抽屉中，使用 Lease、150ms pulse 和 500ms TTL；页面隐藏/失焦/关闭会停止 pulse、发 `stop_motion` 并释放 Lease。

## 3. 火情与三种处置

火情支持自动上报和地图人工创建，按 message/event/fingerprint 时间窗去重。确认后可选择：

1. `DEPLOY_BLANKET`：展开灭火帐。
2. `SPRAY_AGENT`：喷射灭火剂。
3. `DEPLOY_THEN_SPRAY`：先展开灭火帐，再喷射灭火剂。

选择会固化到任务参数和审计，未经选择不得创建灭火任务。平台只表达业务指令与状态，不实现车端执行机构。

## 4. 预设位置与巡检计划

`navigation_presets` 保存世界坐标、地图/语义版本、位置与角度容差、允许接近方向和倒车要求。平台当前明确拒绝未验证的倒车精确任务。车辆报告导航完成后，任务进入 `VERIFYING_FINAL_POSE`；只有定位数据不超过 1 秒、定位质量合格、位置/角度连续 3 帧在容差内才成功。

定时巡检使用五段 cron 与 IANA 时区，包含：

- `misfire_policy`: `SKIP` 或 `RUN_IF_WITHIN_WINDOW`。
- `misfire_grace_seconds`: 允许补跑窗口。
- `overlap_policy`: `SKIP`、`QUEUE` 或 `REJECT`。
- `require_robot_online`、`require_control_contract_verified`、`require_map_contract_verified`。

默认不会在服务器恢复后补跑过期运动任务；机器人忙、离线或真车合同未验证时会留下 occurrence 与明确原因，而不是静默发车。

## 5. 报告与数据

巡检任务记录预设点、停留时长、观测要求、任务时间线、报警、遥测、定位质量和操作事件。完成后可生成 Web、PDF 和 Excel，文件写入私有资产目录，只能通过鉴权下载。视频状态区分 `DISABLED/OFFLINE/CONNECTING/LIVE/ERROR`，无真实流时不会伪造 LIVE。
