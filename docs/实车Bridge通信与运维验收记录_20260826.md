## 数据 ownership 风险

```text
DUPLICATE_UPLINK_RISK=MEDIUM
```

1. CANONICAL_MQTT 与 `_platform/compat` 两路可以影响同一车辆通道。
2. 缺少严格 per-channel ownership 仲裁。
3. 旧 ROS_COMPAT 一旦重新上行，可能把 profile/source_kind 拉回 ROS_COMPAT。

当前实时 CANONICAL_MQTT：`availability / heartbeat / capabilities / status / command_ack`
当前陈旧 ROS_COMPAT：`battery / odom / pose`
当前无：`smoke / bottom_ir / estop / roof_* / top_ir`

处理顺序：**先退役/隔离旧 compat 对应通道，最后才允许 source_kind migration**。
