# 现场协议输入项

平台工程化已完成；ROS2 正式合同继续使用下列参数模板。首台 ROS1 Noetic 实车的已知接口与只读模板见 [ROS1 Noetic 实车只读兼容接入说明](ROS原生兼容接入说明.md) 和 [ROS1只读接入参数模板.yaml](../integration/ros1/ROS1只读接入参数模板.yaml)。

ROS1 现场仍需 OWNER 确认：vehicle ID、真实启动 launch/control_mode、物理车头与 URDF +X、map version/checksum、主控管理 IP、物理急停、`/dev/ttyUSB1` 的 BMS/烟雾归属、视频与灭火硬件计划。上述值不会由平台猜测，也不阻塞只读接入。

平台不得猜测 ROS topic 或设备参数。参数模板：[ROS2对接参数模板.yaml](../integration/ros2/ROS2对接参数模板.yaml)。
