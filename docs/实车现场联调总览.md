- **Bridge runtime SHA = `13c8692...`**：车端实际运行的通信层代码基线。本文件之后的文档收尾 commit **不会**改变它。

## 5. 当前事实锚点（禁止改写）

- `BRIDGE_STUB_MODE=false`、`FIREBOT_SUPPORTED_COMMANDS=`（空）、`FIREBOT_SENSORS=`（空）、`FIREBOT_LOCATION_ENABLED=false`。
- Bridge 只转发命令到 `/firebot_bridge/command`，只有 ROS 明确回 `ACCEPTED` 才向 MQTT 回 `accepted`；无 feedback 回 `rejected + BRIDGE_ADAPTER_NOT_CONNECTED`。
- 服务器只做只读验证与受控观察，不 `git pull`、不 `server-update.sh`、不做数据库/`source_kind` migration。
- `REAL_CONTROL=NOT_IMPLEMENTED`：任何“按钮存在 / topic 存在”都不等于“真车能力已完成”。
