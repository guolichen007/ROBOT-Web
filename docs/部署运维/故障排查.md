# 故障排查

| 现象 | 检查 |
| --- | --- |
| 8080 无法访问 | `docker compose ps`、Nginx/API/web health、端口占用 |
| Docker 不可用 | 启动 Docker Desktop/Engine，检查 WSL2 和 `docker info` |
| PostgreSQL/Redis 失败 | ready checks、容器日志、volume、secret/URL |
| MQTT 连接失败 | Broker health、1883/8883、TLS CA、用户名、ACL、LWT |
| R001 OFFLINE | availability、1Hz heartbeat、vehicle_id、boot_id、ACL |
| Mock 无位置 | mock/ingress 日志、Schema 1.2、map_checksum、10Hz rate limit |
| WebSocket 断开 | ws ticket、Origin、Redis Stream、反向代理 Upgrade |
| lease conflict | 查看 holder/expiry，管理员 force-release；不得绕过互斥 |
| ACK timeout | command_id、target_boot_id、车端本地校验、command_ack topic |
| map mismatch | robot map_code/version/checksum 与 Published 目标版本 |
| wrong boot | 先完成 availability/heartbeat/capabilities，禁止旧 boot 重放 |
| Media OFFLINE | stream registry、publisher token、MediaMTX path、ticket expiry |
| backup/restore 失败 | SHA256、磁盘、migration、月分区、assets 权限 |
| TLS 失败 | CA/server cert/key、SAN/hostname、有效期、8883/443 |
| firebot.lan 打不开/502 | `Resolve-DnsName` 是否 → `.101`、`curl.exe --noproxy "*" -i http://firebot.lan/health/ready`、代理 bypass `firebot.lan`/`192.168.110.*`（详见 [服务器部署](服务器部署.md)） |

仍不能解决时保存对应服务日志和 request_id/command_id，不要在工单中粘贴 secret。
