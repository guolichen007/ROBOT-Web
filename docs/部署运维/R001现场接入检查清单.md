      SIGHUP 原地生效；`R001_MQTT_CREDENTIAL_ROTATED=NO`）

## 车端逐项

1. [ ] Ubuntu/ROS Noetic 环境确认（`rosversion -d` = noetic）
2. [ ] 车端 checkout 对应 integration package **exact SHA**（与服务器 FINAL_HEAD_SHA 同一次发布）
3. [ ] `catkin_make`（工作区级编译通过）
4. [ ] bridge 单元/启动测试（firebotctl vehicle install --sha <SHA> → verify）
5. [ ] 准备 `/etc/firebot/bootstrap.env`（`FIREBOT_SERVER_URL=https://firebot.youdaozd.com`，禁止 IP/HTTP/Tailscale）
      + `/etc/firebot/mqtt-ca.crt`（服务器下发 U-Dao private CA 的 ca.crt；不是 secret）
6. [ ] `firebotctl vehicle enroll R001 --token <TOKEN>`（HTTPS 走 Ubuntu 系统 CA，禁止 `-k`/`--cacert`）
7. [ ] 确认车端 `VEHICLE_AGENT_V1_DOWNLINK_ENABLED=false`
8. [ ] MQTT connect（TLS 验证通过；`vehicle_agent availability online` 上报）
9. [ ] heartbeat/status/capabilities 连续上报（平台 `check_real_vehicle_readonly.py` 观测）
10. [ ] SRT RGB（R001-roof_rgb，per-vehicle token + 平台共享加密 passphrase；
        secret 落 `/etc/firebot/media-secret.env` 0600 root:root）
11. [ ] SRT thermal（R001-roof_thermal）
12. [ ] 断网/LWT/reconnect：人工断网 → 平台观测 offline → 恢复 → online（
      `check_real_vehicle_readonly.py --require-offline-cycle` → `REAL_ROBOT_LWT_RECOVERY=PASS`）
