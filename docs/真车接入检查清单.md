## 安全配置

- [ ] `FIREBOT_SENSORS=`（空）

## 链路与身份

- [ ] MQTT TLS / canonical vehicle_id 身份 PASS
- [ ] R1：无 roscore 时 MQTT 仍在线、heartbeat 持续、boot_id/PID 不变
- [ ] R2：Bridge 在线后启动 roscore，adapter 自动初始化，Bridge 不重启
- [ ] R3：broker 受控断开/恢复（`OWNER_APPROVAL_REQUIRED`）
- [ ] R4：`MANUAL_ROSTOPIC` battery=67.5 链路到 Web

## 数据真实性

- [ ] `REAL_BATTERY_PROVIDER=NOT_VERIFIED`（R4 手工发布不代表真实 provider）
- [ ] smoke 无真实源时不声明 `smoke`、不伪造 0
- [ ] `source_kind` 保持现状，未迁移
- [ ] control flags 全部保持 `false`
- [ ] `REAL_CONTROL=NOT_IMPLEMENTED`

## 命令语义（重要）

- [ ] 当前 `supported_commands=[]`：任何命令在 validator 回 `COMMAND_UNSUPPORTED`，不会转发 ROS
- [ ] `BRIDGE_ADAPTER_NOT_CONNECTED` 仅在“命令已通过 capability 校验并成功转发 ROS 后无 feedback”时出现
- [ ] 只有 ROS 明确回 `ACCEPTED`，Bridge 才回 MQTT `accepted`
