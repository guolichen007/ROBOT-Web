# 系统架构

Vue 只连接统一 Nginx 入口；浏览器不直接连接 MQTT、RTSP 或数据库。FastAPI 是模块化单体，MQTT ingress、Command Dispatcher、Task Worker 是职责明确的独立进程。

PostgreSQL 保存用户、地图、任务、命令、报警、审计等业务事实；Redis 保存 latest、heartbeat TTL、manual lease、短期相关性和可重放实时 Stream。业务事实必须先 commit PostgreSQL，commit 后才发布 Redis delta。

Durable command 在同一事务写 `commands + outbox_events`，dispatcher 按 at-least-once 发布并保持相同 `command_id`。manual pulse 使用 Redis Pub/Sub、QoS0、TTL 500ms，不进入 outbox。stop/e-stop 使用独立高优先级 Stream，但数据库事实先提交。

Vehicle 消息使用 `boot_id`；Platform command 使用 `target_boot_id`。`robot_boot_sessions` 防止旧 boot 消息回滚当前会话。e-stop 可以使用 null target 进行离线安全尝试，但必须等待 ACK。

MediaMTX 的 read/publish 鉴权回调平台 `/api/v1/media/authorize`。Web ticket 绑定 user、robot、camera、stream 和 expiry；管理 API 只在容器网络或本机调试。

## 软件控制核心链

```text
Web → API → Dispatcher → MQTT → Vehicle Bridge → ROS → Control
```

- 车端唯一入口 `firebotctl`（`integration/ros1/firebotctl`）；底层脚本 vehicle-install.sh / vehicle-runtime.sh 只做单一职责模块。
- 火警告警生命周期（生产合同）：`NEW → ACKNOWLEDGED → CONFIRMED → RESOLVED`，禁止跳变。

## 工业中控 HMI

实时监控页采用单屏高性能 HMI：低饱和石墨灰承载正常状态，蓝色表示当前选择/运行，琥珀表示警告，红色只用于火情、严重故障和软件急停。首页 60% 二维停车场地图，40% 车顶实时视频、传感器与活动报警；主要控制位于底部。

地图按实际停车场拓扑显示车位、道路方向、规划/已执行轨迹、机器人航向、火情车位和右侧检测扇区。检测几何使用传感器相对 `base_link` 的 `x/y/yaw` 安装外参，以检测扇区与车位 polygon 相交作为覆盖判定。

操作语义：

- 开始巡检：创建使用已发布地图快照的巡检任务。
- 停止巡检：并行 `cancel_task` 与高优先级 `stop_motion`；任务取消、停止 ACK 与连续 5 帧新鲜低速遥测全满足后才显示「车辆已停止」。
- 返回等待区：独立返回命令，不与灭火任务静默冲突。
- 软件急停：单击立即发送，不等确认窗；ACK 前只显示「等待确认」，不等于物理急停。
- 手动控制：抽屉内，Lease + 150ms pulse + 500ms TTL；页面隐藏/失焦/关闭即停 pulse、发 `stop_motion`、释放 Lease。

## ROS2 集成（canonical 主路径）

正式 ROS2 合同与可交付文件位于 [integration/ros2](../../integration/ros2/现场对接说明.md)。本仓库不包含 ROS2 node、SLAM、Nav2、驱动、底盘或执行机构实现。

## ROS1 原生只读兼容（边界，非主路径）

首台 ROS1 Noetic 实车在命令链路形成前提供**只读兼容接入**：

```text
mqtt_bridge → ros-compat-adapter → _platform/compat/R001/* → mqtt-ingress → Redis/PostgreSQL/Web
```

当前仓库不存在 ROS1 command publisher 与 ACK translator，因此 `ROS_COMPAT_DOWNLINK_IMPLEMENTED=false` 是代码级不变量，所有下行返回 `ROS_COMPAT_READ_ONLY`。将来允许控制前必须完成 command/ACK bridge、control_mode==3 运行时验证、cmd_vel 仲裁（优先级 `SAFETY STOP > MANUAL > NAVIGATION`）、500ms 单调时钟本地 watchdog、per-command capability、map version/checksum 匹配。
