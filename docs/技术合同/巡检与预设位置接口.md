# 巡检与预设位置接口

所有接口统一前缀 `/api/v1`，使用 Bearer access token。创建运动任务必须带 `Idempotency-Key`。

## 预设位置

- `GET /navigation-presets`
- `POST /navigation-presets`（仅 DRAFT 地图）
- `POST /robots/{robot_id}/navigate-preset`

导航请求：

```json
{"navigation_preset_id": "preset-uuid"}
```

平台通过 Canonical 1.2 的 `patrol` 命令下发，并在 `params.mission_kind=NAVIGATE_TO_PRESET` 中表达平台业务意图；不因此升级或分叉车云 Schema。返回任务会经历 `QUEUED → ACCEPTED → EXECUTING → VERIFYING_FINAL_POSE → SUCCEEDED/FAILED`。

## 巡检计划与定时

- `GET /patrol-plans`
- `POST /patrol-plans`
- `POST /patrol-schedules`

```json
{
  "patrol_plan_id": "plan-uuid",
  "cron_expression": "0 8 * * *",
  "timezone": "Asia/Shanghai",
  "enabled": true,
  "misfire_policy": "SKIP",
  "misfire_grace_seconds": 0,
  "overlap_policy": "SKIP",
  "require_robot_online": true,
  "require_control_contract_verified": true,
  "require_map_contract_verified": true
}
```

## 停止巡检

- `POST /robots/{robot_id}/stop-patrol`
- `GET /stop-operations/{operation_id}`

停止操作状态：`STOP_REQUESTED`、`TASK_CANCEL_ACCEPTED`、`STOP_COMMAND_ACCEPTED`、`VERIFYING_STATIONARY`、`VEHICLE_STATIONARY_CONFIRMED`、`UNCONFIRMED`、`FAILED`。

## 右侧检测与集成状态

- `GET /robots/{robot_id}/sensor-profiles`
- `PUT /robots/{robot_id}/sensor-profiles/{channel}`
- `GET /robots/{robot_id}/detection-coverage`
- `GET/PUT /robots/{robot_id}/integration`
- `GET /integration/ros-native/discoveries`
- `POST /integration/ros-native/aliases`

数据通道状态只允许 `CONNECTED/STALE/NOT_CONNECTED/ERROR/UNSUPPORTED`，未知数值返回 `null`，不使用 0 冒充。

## 巡检报告

- `GET /patrol-reports`
- `POST /patrol-reports/tasks/{task_id}`
- `GET /patrol-reports/{report_id}/download/html`
- `GET /patrol-reports/{report_id}/download/pdf`
- `GET /patrol-reports/{report_id}/download/xlsx`

下载接口要求有效权限与认证，不暴露资产目录的直接静态 URL。
