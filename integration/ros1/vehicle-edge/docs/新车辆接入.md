# 新车辆接入（R003/R004 标准流程）

车辆只是数据：DEVICE_ID / DISPLAY_NAME / SITE_CODE / PROFILE_ID。
禁止复制 R002 目录/改源码/改 MQTT IP/人工复制 password/人工编辑 systemd。

```text
服务器（管理员）：
  firebotctl fleet preregister firebot-vehicle-03 --name R003 --site-code <SITE>
  firebotctl fleet register firebot-vehicle-03          # 现场即时签发一次性 token

车端（现场，按顺序）：
  firebotctl vehicle edge-init --runtime-user tl
  # bootstrap 两个文件（服务器下发）：
  #   config/bootstrap.env    FIREBOT_SERVER_URL=https://firebot.youdaozd.com
  #   certs/mqtt-ca.crt       U-Dao private CA（公开信任材料）
  firebotctl vehicle readonly-preflight --phase bootstrap \
    --device-id firebot-vehicle-03 --expected-sha <FINAL_SHA>
  firebotctl vehicle migration-stop-legacy             # 仅迁移车辆需要；新车跳过
  firebotctl vehicle enroll firebot-vehicle-03 --token <TOKEN>
  firebotctl vehicle edge-install --sha <FINAL_SHA>
  firebotctl vehicle edge-verify --sha <FINAL_SHA>
  firebotctl vehicle readonly-preflight --phase enrolled --expected-sha <FINAL_SHA>
  firebotctl vehicle readonly-start
  vehicle-connection-status                            # 期望 Overall HEALTHY
```

约束：enroll 前 Bridge/Edge 必须 inactive（token 零消费门）；install ≠ start；
CONTROL_ENABLED=NO / CONTROL_ACTIVE=NO / FIREBOT_SUPPORTED_COMMANDS=（空）全程保持；
真车控制需独立阶段授权。
