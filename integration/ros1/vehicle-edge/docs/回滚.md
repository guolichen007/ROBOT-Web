# 回滚（Vehicle Edge）

本文区分三种**互不相同**的回滚，绝不可混用（B0-FIX-CODE / 规格四十四）。

## A. Tools rollback（管理平面回滚）

只切换管理工具 release，不影响通信运行时：

```text
firebotctl vehicle tooling-status          # 只读查看 tools current/previous
<edge-home>/tools/current  <->  <edge-home>/tools/previous
```

- 实现：`vehicle-edge/install/tools-release-manager.sh rollback`。
- 语义：只切换 `tools/current` 与 `tools/previous` 两个 symlink；**绝不**停止/启动
  Edge、停止/启动 legacy、改 MQTT、改配置、改 secret、改 Control、改 ROS。
- 输出 `MANAGEMENT_PLANE_ROLLBACK=PASS` + `DATA_PLANE_UNCHANGED=YES`。
- 与数据平面 `releases/current/previous` 完全无关。

## B. Edge communication rollback（通信迁移回滚）

**唯一**通信迁移回滚入口：`firebotctl vehicle edge-rollback`。

新链路失败（cutover 之后任一步）→ ROLLBACK_REQUIRED=YES，执行：

```text
firebotctl vehicle edge-rollback
```

流程（fail-closed；幂等）：

```text
0. Control 安全门：firebot-control disabled + inactive（否则 REJECTED / CONTROL_NOT_SAFE）
1. legacy unit（firebot-bridge.service）仍存在（否则 REJECTED / LEGACY_UNIT_MISSING）
2. legacy bridge.env 仍指 100.110.31.112（漂移 → REJECTED / LEGACY_CONFIG_DRIFTED /
   MANUAL_RESTORE_REQUIRED=YES，绝不自动覆盖 /etc/firebot/*）
3. 幂等分派：
   A. edge active + legacy inactive   → 正常回滚
   B. edge inactive + legacy inactive → 启动 legacy 并验证
   C. edge inactive + legacy active   → EDGE_ROLLBACK=ALREADY_ROLLED_BACK
   D. edge active + legacy active     → REJECTED / MUTUAL_EXCLUSION_VIOLATED（不自动猜修）
4. disable --now firebot-vehicle-edge（不删除 service/unit/release）
5. enable --now firebot-bridge（legacy）
6. 验证 MQTT_HOST=100.110.31.112 + mqtt_connected=true → LEGACY_ROLLBACK=PASS
```

**绝不**：自动覆盖 `/etc/firebot/*`、自动恢复 secret、catkin_make、修改 Control、
修改 Tailscale。`backups/legacy/` 是 DISASTER_RECOVERY_ARTIFACT，不是自动覆盖源；
legacy config 损坏 → `MANUAL_RESTORE_REQUIRED=YES` → 进入人工灾难恢复流程。

## C. Legacy / full-install rollback（旧整车安装回滚）

旧 `firebotctl vehicle rollback` → `vehicle-install.sh rollback`（回 previous
Bridge+Control 并 `catkin_make` 重编译），属于老式整车软件安装语义。

**不能**用于当前公网通信 cutover。生产 Vehicle Edge tools 中该命令被拒绝：

```text
LEGACY_FULL_INSTALL_COMMAND_NOT_AVAILABLE_IN_EDGE_TOOLS
```

## 回滚后的云端状态

- 新 firebot-vehicle-edge.service / releases 保留 disabled/inactive 作为 artifact，不删除。
- 云端 firebot-vehicle-02 identity/credential/已消费 token 不删除（保持 OFFLINE、
  enabled=false、supported_commands=[]）；重试走 fleet register credential ensure。
- 迁移期间 Tailscale 保持 ROLLBACK_CHANNEL_ONLY（不得 down/logout/卸载/禁用）。
