# 连接状态说明

## 健康状态模型

```text
HEALTHY(0) / DEGRADED(10) / OFFLINE(20) / UNSAFE(30) / CONFIG_ERROR(40) / INTERNAL_ERROR(50)
```

- UNSAFE：control active/enabled、supported_commands 非空、legacy+edge 双 active（互斥违反）
- OFFLINE：edge service 未运行
- DEGRADED：service 运行但 MQTT 断开 / 心跳年龄 >15s
