# 现场操作（正式入口唯一）

正式入口：`firebotctl`（Fleet + Lifecycle dispatcher）+ `firebot-edge`（Edge Home 主 CLI）。

```text
edge-init / edge-install / edge-verify / readonly-preflight / readonly-start /
migration-stop-legacy / enroll
```

底层 systemctl 属 DEVELOPER/DEBUG ONLY：
- 禁止手改 `config/bridge.env`、`secrets/mqtt.env`、`config/identity.env`
- 禁止 `systemctl enable --now firebot-vehicle-edge`（只允许 readonly-start）
- 禁止 `systemctl enable --now firebot-bridge`（legacy 启动仅限回滚流程）

连接状态：
```text
vehicle-connection-status            人类输出
vehicle-connection-status --json     JSON（不含 secret）
vehicle-connection-watch [--interval 2] [--json] [--once]
vehicle-connectivity-selftest        主动只读自检（不建第二 MQTT session、不发 probe）
vehicle-edge-doctor                  完整安装体检（不输出 secret value）
```

旧 `firebotctl vehicle install` 为 LEGACY / FULL VEHICLE INSTALL，
NOT FOR READONLY CONNECTIVITY MIGRATION。
