# 故障排查

1. `vehicle-connection-status`：Overall 非 HEALTHY → 按 exit code 定位
2. `vehicle-connectivity-selftest`：layout/config/DNS/TCP/TLS/service/心跳逐项
3. `vehicle-edge-doctor`：完整安装体检（含权限/互斥/NTP/磁盘/Control safety）
4. `firebot-edge logs`：本地 logs + journalctl（自动脱敏）

常见：
- EDGE_RUNTIME_USER_NOT_CONFIGURED → 先 `edge-init --runtime-user tl`
- EDGE_INSTALL=REJECTED / LEGACY_BRIDGE_ACTIVE → 先 `migration-stop-legacy`
- ENROLL=REJECTED / LEGACY_BRIDGE_STILL_ACTIVE → token 未消费；先停 Bridge 再重试
- MQTT 断开：查 selftest 的 DNS/TCP/TLS 项；TLS 用 certs/mqtt-ca.crt 握手验证
- 心跳年龄大：本地 status.json 的 last_heartbeat_at / heartbeat_age_seconds

诊断工具绝不：使用生产密码新建第二 MQTT session、publish/subscribe probe、
修改 assignment、发送 command（避免顶下线真实 Bridge client）。
