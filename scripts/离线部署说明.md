# Firebot 固定镜像离线部署

1. Windows 上运行 `scripts/01-test-pull.ps1` 验证 Docker Engine 和镜像仓库。
2. 运行 `scripts/02-pull-all.ps1 -OutputDirectory <安全输出目录>` 拉取、归档并生成 SHA-256。
3. 将输出目录和仓库代码复制到 Ubuntu 服务器。
4. 在服务器运行 `sh scripts/03-load-images.sh <归档路径>`；脚本会先验证校验和再加载镜像。
5. 按 `docs/服务器部署指南.md` 创建 secret/TLS/ACL 后启动 `docker-compose.server.yml`。

镜像归档、校验文件和实际 secret 不得提交 Git。输出目录应位于仓库之外。
